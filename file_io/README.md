# File I/O

This project is about learning how to work with files in C using POSIX system calls.

## Description

In this project, I learned how to:

- Open and close files using `open()` and `close()`
- Read data from files using `read()`
- Write data using `write()`
- Work with file descriptors
- Use POSIX file I/O
- Handle errors when working with files
- Understand file permissions and flags

## Requirements

- Ubuntu 20.04 LTS
- GCC
- Betty coding style
- All files are compiled with:

```bash
gcc -Wall -Werror -Wextra -pedantic *.c -o <output>
